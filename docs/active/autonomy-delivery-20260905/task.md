# Small-batch autonomy delivery

## Scope

The user authorized comparison tasks, evidence-based local tuning, qualified real applications, merge and push. Normal batches are 5-10 jobs with a modest experiment budget. The latest instruction excludes previously attempted employers from the real cohort. Root owns integration, real data/browser/Submit, combined checks and Git delivery; delegated tests use isolated resources.

## Delivered behavior

- Supervisor separates legal waits from repeated no-progress and counts one tool-call lifecycle once, while retaining deadlines and effect-unknown stops.
- CLI/App Server share resolved model/effort and provenance. Defaults remain Sol/high; no new production App Server write authority is enabled.
- Material admission reads the actual upload PDF; contradictory sidecars cannot override it, and unextractable text stays unknown.
- Bounded routine filling supports ordinary Workday/SmartRecruiters fields. Default off; canary retains the second live audit and SubmissionGate. Country aliasing requires an exact ordinary-country label.
- Small-batch next/progress uses durable state and bounded references. Stored recipe experience is value-free, validated and observational.
- Preferred job skills no longer become hard gaps merely because a broad experience marker appears earlier. Temasek qualifies using the same factual profile and materials.
- The official SuccessFactors European suffix is recognized by credential relay; other capabilities and root/page/password/Submit restrictions remain unchanged.
